# 大一學習資料庫

中國醫藥大學醫療資訊學系 · 微積分（蔡豐聲）· CPE（C++）

資料在 `data/`，週曆在 `app/`。完整文字總表見 [`學習計畫.md`](./學習計畫.md)。調整進度時以週曆為準，不要先擴充系統。

## 行動裝置／線上網頁

推上 `main` 後，GitHub Actions 會自動部署：

**https://ginobygino.github.io/Freashmanschedual/**

第一次請到 GitHub repo → **Settings → Pages**，Source 選 **GitHub Actions**。

進度存在瀏覽器本機，手機與電腦不會自動同步；要備份請用頁面「匯出目前進度」。

## 啟動週曆（本機）

```bash
cd app
npm install
npm run dev
```

瀏覽器會開 `http://localhost:5173`。

- 拖曳卡片改期；考試與 CPE 報名鎖住
- 雙擊空格新增時段
- 題庫可把狀態改成完成／卡住
- 調整存在瀏覽器；請用「匯出目前進度」備份，必要時再貼回 `data/`

若改了 `scripts/generate-data.mjs`，在專案根目錄執行 `npm run data` 會覆寫 JSON（不會覆寫你放進去的 PDF）。

## 程式路線（到 10/6 先拿前三題）

題庫在 `data/programming/problems.json`：一顆星 49 題＋ BFS／DFS 起手 11 題。

1. 一顆星選集（每次考試至少一題來自這裡）
2. 模擬、字串、簡單數學
3. 你已會的排序／搜尋改練 UVa 敘述
4. DFS／BFS：網格連通塊與最短步

不要在 10 月前深挖 DP。交題用 [瘋狂程設](https://cpe.mcu.edu.tw/environment.php)、[vjudge](https://vjudge.net) 或 UVa。語言用 C++。
